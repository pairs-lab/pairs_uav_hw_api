# pairs_uav_hw_api

PAIRS UAV hardware API — the abstraction layer (pluginlib interface) between the
PAIRS UAV System and a low-level flight controller. Provides the `PairsUavHwApi`
plugin base class, the HwApiManager nodelet, and a dummy API implementation.

Ported from the BSD-3-Clause [ctu-mrs/mrs_uav_hw_api](https://github.com/ctu-mrs/mrs_uav_hw_api) (`mrs_*` → `pairs_*`).

This is the **ros1** branch (ROS 1 Noetic, catkin). For ROS 2 Jazzy, see the `ros2` branch.
